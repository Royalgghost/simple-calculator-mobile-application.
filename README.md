# TP3 React Native Calculator

A simple calculator mobile application built with React Native and Expo. This project allows users to enter two numbers, choose an arithmetic operator, and calculate the result directly on the device.

## Project Team

- Azzat
- Nouamane
- Hnid
- Aimane

## Features

- Enter two numeric values
- Select an operator: `+`, `-`, or `*`
- Calculate the result
- Clear the form and reset the values
- Clean and responsive mobile interface

## Tech Stack

- React Native
- Expo
- JavaScript

## Prerequisites

Before running the project, make sure you have installed:

- Node.js (LTS recommended)
- npm or yarn
- Expo CLI
- Android Studio / Xcode for emulation (optional)

## Installation

1. Clone the repository:

```bash
git clone https://github.com/Royalgghost/TP3-react-native-Azzat-Nouamane-Hnid-Aimane.git
cd TP3-react-native-Azzat-Nouamane-Hnid-Aimane
```

2. Install dependencies:

```bash
npm install
```

## Run the App

Start the Expo development server:

```bash
npm start
```

Then choose one of the following:

```bash
npm run android
npm run ios
npm run web
```

## App Behavior

The app includes:

- Two input fields for the numbers
- An operator selection panel
- A calculate button
- A result display section
- A clear button to reset the state

## Example

- First number: `12`
- Second number: `8`
- Operator: `+`
- Result: `20`
